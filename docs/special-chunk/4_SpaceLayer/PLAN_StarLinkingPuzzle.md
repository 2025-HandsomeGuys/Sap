# [4층 우주층] 별빛 잇기 퍼즐 (Star Linking Puzzle) 기획서

## 1. 개요
*   **목표:** 4층 우주층 테마에 맞는 '별자리' 기반의 퍼즐 기믹 구현.
*   **핵심 재미:** 주변 환경의 힌트를 관찰하고, 흩어진 노드들을 연결해 올바른 별자리 모양을 완성하는 추리 및 조작의 재미.

## 2. 핵심 구성 요소 (Components)

### 2.1. 별 노드 블록 (Star Node Tile)
*   우주층 퍼즐 방(Special Chunk) 곳곳에 배치되는 **파괴 불가능한 상호작용 블록**.
*   **상태:**
    *   `Idle`: 기본 상태. 은은한 빛을 냄.
    *   `Selected`: 플레이어가 연결을 시작하기 위해 선택한 상태. 밝게 빛나며 소리가 남.
    *   `Connected`: 다른 노드와 선으로 연결된 상태.
*   **상호작용:** 특수 도구를 이용해 우클릭 시 선택/연결됨. 곡괭이로 치면 해당 노드에 연결된 선이 끊어짐.

### 2.2. 별빛 지팡이 (Astro Wand) - 연결 전용 도구
*   노드 사이를 잇기 위한 퍼즐 전용 아이템. (일반 블록 상호작용과 겹치지 않게 전용 도구를 사용하는 것을 권장)
*   **작동 방식:**
    1. 지팡이를 들고 노드 A 우클릭 -> 노드 A가 `Selected` 상태로 변경.
    2. 이어서 노드 B 우클릭 -> 노드 A와 B 사이에 시각적인 빛의 선(Line Renderer) 생성 및 내부 데이터(Edge) 연결.

### 2.3. 별자리 퍼즐 매니저 (Star Puzzle Manager)
*   퍼즐 청크 내부에 배치되어 퍼즐의 진행 상태를 관리하는 컨트롤러 스크립트.
*   **데이터 구조:**
    *   `List<StarNodeTile> nodes`: 방 안의 모든 별 노드.
    *   `List<Edge> currentConnections`: 현재 플레이어가 이은 선들의 목록.
    *   `List<Edge> targetConnections`: 해당 방의 정답(목표 별자리) 선들의 목록.
*   **검증 로직:** 플레이어가 선을 새로 긋거나 지울 때마다 `currentConnections`와 `targetConnections`가 일치하는지 비교 검사.
*   **클리어 처리:** 정답과 일치하면 보상 트리거 발동 (잠긴 문 개방, 보상 상자 스폰 등).

### 2.4. 힌트 제공 시스템 (Hint System)
*   **배경 힌트:** 퍼즐 방 근처의 배경 벽(Background Wall)에 정답 별자리 모양이 다른 색상의 야광 도트로 희미하게 찍혀 있음.
*   **퍼즐 석판:** 방 입구에 상호작용 가능한 비석을 두어, 우클릭 시 정답 별자리 이미지를 UI 팝업으로 보여줌.

## 3. 구현 프로세스 (Implementation Steps)

1.  **타일 및 아이템 데이터 생성:**
    *   `StarNodeTile` 타일 데이터 추가 (파괴 불가).
    *   `AstroWand` 아이템 추가 (또는 플레이어 기본 상호작용에 별빛 잇기 모드 추가).
2.  **시각 효과 (VFX) 구현:**
    *   노드가 선택되었을 때의 파티클 및 색상 변경.
    *   두 노드를 잇는 우주 느낌의 반투명한 `LineRenderer` 프리팹 제작.
3.  **핵심 스크립트 작성:**
    *   `StarPuzzleManager.cs` 작성 (퍼즐 정답 검증 및 이벤트 발동 로직).
    *   플레이어 상호작용 시스템에 별 노드 선택/연결 로직 추가.
4.  **특수 청크 (Special Chunk Settings) 구성:**
    *   맵 생성 시 `SpecialChunkManager`가 불러올 별자리 퍼즐 방 프리셋 제작.
    *   프리셋 저장 시 정답 연결 리스트(`targetConnections`) 데이터 포함.

## 4. 기획 결정 필요 사항 (Open Questions)
*   **[Q1] 잘못된 연결 시 페널티:** 오답인 선을 그었을 때 단순히 선을 지울 것인지, 아니면 함정이 발동해 몬스터가 나오거나 플레이어에게 피해를 줄 것인지?
*   **[Q2] 연결 초기화 방식:** 곡괭이로 노드를 일일이 쳐서 선을 지울지, 아니면 방 한쪽에 '리셋 레버'를 두어 한 번에 싹 지울지?
*   **[Q3] 도구 획득 방식:** `AstroWand`를 우주층 초입에서 기본으로 줄지, 아니면 보스 드랍 등 탐험(메트로배니아)을 통해 얻어야만 별자리 퍼즐에 도전할 수 있게 할지?

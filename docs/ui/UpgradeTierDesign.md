## 개요
- 업그레이드 패널에서 각 계층(Tier)을 시각적으로 명확하게 구분하고, 아직 해금되지 않은 계층을 불투명한 패널로 가리는 기능을 구현했습니다.
- 사용자가 제공한 이미지와 같이, 각 계층별 배경과 잠금 오버레이를 적용하여 게임 진행 상황에 따른 시각적 피드백을 강화했습니다.

## 기존 구조 요약
- **UpgradeUI**: 업그레이드 트리의 노드와 연결선을 생성하고 관리하는 메인 클래스입니다.
- **UpgradeNodeSO**: 각 업그레이드 노드의 데이터(좌표, 계층 인덱스 등)를 담고 있습니다.
- **UpgradeManager**: 노드 및 계층의 해금 상태를 관리하는 로직 클래스입니다.
- **OrthogonalUILineRenderer**: 노드 간의 직각 연결선을 그리는 컴포넌트입니다.

## 변경 사항 요약
- **UpgradeTreeSO**: 계층 정보(이름, 해제 조건 텍스트 등)를 저장할 수 있는 `TierInfo` 구조를 추가했습니다.
- **UpgradeTierUI (신규)**: 각 계층의 배경, 이름, 잠금 오버레이를 관리하는 클래스를 추가했습니다.
- **UpgradeUI**: 
    - 4개의 레이어(`BackgroundLayer`, `LineLayer`, `NodeLayer`, `OverlayLayer`)를 도입하여 렌더링 순서를 제어합니다.
    - 노드들의 좌표를 기반으로 각 계층의 영역을 자동으로 계산하여 배경과 오버레이의 크기를 조절합니다.
    - 계층 상태 업데이트 로직을 추가하여 해금 시 실시간으로 오버레이가 사라지도록 했습니다.

## 전체 구조 설명
- **레이어 구조 (Back to Front)**:
    1. **BackgroundLayer**: 각 계층의 배경 및 계층 번호 표시.
    2. **LineLayer**: 노드 간의 연결선.
    3. **NodeLayer**: 개별 업그레이드 슬롯(Slot).
    4. **OverlayLayer**: 잠긴 계층을 가리는 불투명 패널 및 해제 조건 텍스트.
- **데이터 흐름**: `UpgradeManager`에서 계층 해금 여부를 확인하면, `UpgradeUI`와 `UpgradeTierUI`가 이를 반영하여 화면을 갱신합니다.

## 신규 기능 상세
- **자동 영역 계산**: `UpgradeUI`는 각 계층에 속한 노드들의 Y축 위치를 분석하여 자동으로 계층 배경의 높이와 중앙 위치를 설정합니다. 이를 통해 수동 설정 없이도 깔끔한 레이아웃을 유지합니다.
- **레이어 분리 시스템**: 단순히 프리팹을 생성하는 것이 아니라, 생성 후 내부 요소들을 4개의 레이어 컨테이너로 재배치함으로써 연결선이 배경 위에, 노드가 연결선 위에, 오버레이가 모든 것 위에 오도록 보장합니다.

## 기술적 선택 이유
- **Raycast Blocking**: 잠금 오버레이(`lockedOverlay`)가 `OverlayLayer`에 위치하여 노드들을 덮음으로써, 잠긴 상태에서는 하위 노드들을 클릭할 수 없도록 자연스럽게 상호작용을 차단했습니다.
- **RectTransform Stretch**: 다양한 해상도와 스크롤 영역에 대응하기 위해 가로 방향으로 꽉 차는 스트레치 설정을 자동으로 적용합니다.

## 적용 방법
1. **파일 추가**: `UpgradeTierUI.cs`를 프로젝트에 추가합니다.
2. **ScriptableObject 설정**: `UpgradeTreeSO` 에셋에서 `Tiers` 리스트에 각 계층 인덱스에 맞는 정보를 입력합니다 (예: Index 2, Name "기초 공업 II").
3. **프리팹 제작**:
    - `UpgradeTierUI` 프리팹을 만듭니다. 
    - 자식 오브젝트로 `Background` (배경 이미지 및 텍스트)와 `LockedOverlay` (잠금 패널)를 구성합니다.
    - `UpgradeTierUI` 컴포넌트의 각 필드에 해당 오브젝트들을 할당합니다.
4. **인스펙터 설정**: `UpgradeUI` 오브젝트의 `Tier Prefab` 필드에 방금 만든 프리팹을 할당합니다.

## 확장 및 주의사항
- **가로형 트리 대응**: 현재는 Y축 기준 세로형 계층 구조를 가정하고 설계되었습니다. 가로형으로 변경하려면 `SetupTierRect` 및 범위 계산 로직에서 X축을 기준으로 수정해야 합니다.
- **성능**: `CreateTreeUI`는 UI가 열릴 때 한 번만 호출되므로 노드가 매우 많지 않은 한 성능 영향은 미미합니다.

## 세이브 / 로드 통합
- **자동 저장**: 업그레이드 노드를 해금할 때마다 `SaveManager`를 통해 즉시 파일로 저장됩니다.
- **데이터 보존**: `PlayerStatsController.ToData()` 방식이 수정되어 세이브 시 업그레이드 상태가 유실되지 않도록 보완되었습니다.
- **로드 시 복구**: 게임을 다시 시작하거나 씬을 전환해도 해금된 노드와 계층 상태가 완벽하게 복구됩니다.

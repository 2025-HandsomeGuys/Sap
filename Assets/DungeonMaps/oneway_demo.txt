# 일방향 플랫폼(=) 견본 맵. 트랩 없이 = 의 성질만 순수하게 보여준다.
#
# [= 의 성질]  PlatformEffector2D(useOneWay, surfaceArc=180)
#  - 윗면에서만 충돌한다 → 아래/옆에서는 그냥 통과한다.
#  - 아래에서 점프하면 뚫고 올라가 그 위에 착지한다.
#  - 위에 올라간 뒤에는 아래로 못 내려온다(드롭다운 미지원). 옆으로 걸어 나가야 떨어진다.
#
# [진행 흐름]
#  1) 굴뚝(col1~10, 좌우 벽으로 밀봉). 바닥의 E 에서 그냥 위로 점프만 반복하면
#     = 5단(row14/12/10/8/6)을 뚫고 올라간다. 한 단 오를 때마다 아래로는 못 돌아간다
#     → '래칫(ratchet)' 성질을 몸으로 익히는 구간. 각 단에 $ / r 배치.
#  2) 꼭대기(row6 = 의 윗면)와 상단 통로(row6 W 타일)는 높이가 같다 → 그대로 우측으로 걸어 나간다.
#  3) 통로 끝(col24)에서 우측 낙하 → W 발판 3단(row9 → row12 → row13) 지그재그 하강 → 지상.
#     row13 발판은 지상(보행 row15)에서 2칸 띄운다. 1칸만 띄우면 키 2칸인 플레이어가
#     그 아래를 못 지나가고 보이지 않는 벽이 된다.
#  4) 지상 보너스: col16~19 의 = 는 지상에서 점프 2칸으로 올라가 위의 $ 를 먹는 평범한 발판.
#     그 아래를 지나갈 때 몸이 겹쳐도 막히지 않는다(옆·아래 통과 확인 지점).
#     내려올 때는 반드시 양 끝으로 걸어 나가야 한다.
#  5) 좌측으로 이동해 X 로 탈출. col11 벽 때문에 굴뚝으로는 되돌아갈 수 없다.
#
# [임포트 전 준비] '=' 심볼은 최초 1회 등록이 필요하다.
#  메뉴: Tools/Dungeon/Create One-Way Platform ('=')
#  → Assets/Prefabs/Dungeon/OneWayPlatform.prefab 생성 + DefaultDungeonTileset 에 '=' 등록
#
# [공통 규약]
#  - 좌표는 (row, col), row 0 = 맨 위. 점프 규약: 수직 2칸 상승 / 수평 2~3칸 간격.
#  - W 발판과 달리 = 는 아래 통로를 막지 않으므로, 보행 row 바로 위에 놓아도 안전하다.
#    (플레이어 히트박스가 2칸이어도 = 밑을 지나갈 수 있다)
#  - 낙하 지점은 모두 착지면이 있어 소프트락이 없다. 굴뚝을 놓쳐도 아래 = 위에 다시 선다.

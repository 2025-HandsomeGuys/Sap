# 주식 등락폭 축소 튜닝 (2026-08-27)

## 문제
시세탭 그래프가 "한 방향으로 크게 무너지고 바닥에 눕는" 모양이었다.
화면(최근 25틱) 안에서 고점/저점이 워낙 벌어져서 **아무 저점에서 사서 아무 고점에서 팔면 벌리는** 상태.

## 측정 (틱 시뮬 400틱 × 종목 vol 7종 × 30회, 뉴스 제외)

| 지표 | 변경 전 | 변경 후 |
|---|---|---|
| 평균 \|틱변동\| | 11.7% | 7.8% |
| p95 \|틱변동\| | 20.0% | 13.0% |
| price/base p5 ~ p95 | 0.56 ~ 2.13 | 0.68 ~ 1.62 |
| **25틱 창 고/저 배율 median** | **2.29배** | **1.72배** |
| 같은 값 p90 | 3.70배 | 2.34배 |

## 바꾼 값 (`StockPriceEngine`)

| 상수 | 전 → 후 | 의도 |
|---|---|---|
| `NoiseSigmaFactor` | 0.58 → 0.40 | 평상시 틱 진폭 축소 |
| `AmbientMaxMove` | 0.20 → 0.13 | 노이즈 절대 상한 |
| `MaxTickChange` | 0.40 → 0.28 | 한 틱 총변동 하드캡 |
| `NewsTickCap` | 0.35 → 0.24 | 뉴스 틱 상한(하드캡과 비율 유지) |
| `NewsEffectMultiplier` | 3.0 → 2.2 | 뉴스가 새 하드캡에 항상 붙어 평평해지는 것 방지 |
| `JumpChance` | 0.035 → 0.030 | 희귀 점프 빈도 |
| `JumpUp/Down` | +18~38 / −15~35% → +10~24 / −9~22% | 점프도 새 하드캡 안에 |
| `ReversionDeadbandPct` | 0.35 → 0.18 | **핵심.** 아래 참고 |
| `ReversionBase` | 0.04 → 0.06 | 데드밴드 갓 밖에서의 기본 복원력 |
| `ReversionMax` | 0.22 → 0.26 | 깊은 이탈 복귀력 |
| `ReversionMaxStepPerTick` | 0.08 → 0.05 | 한 번에 확 당기지 않게(진폭은 줄었으니 스텝도 축소) |

### 데드밴드가 핵심인 이유
±35% 안에서는 복원력이 0이라, 가격이 그 폭 안에서 자유 표류하다 한쪽으로 밀리면
그대로 밴드 끝(기준가 ×0.4 / ×10)에 눌러앉는다 — 스크린샷의 "쭉 내려가서 바닥에 평평"이 이것이다.
±18%로 좁히면 평상시에도 약한 복원력이 늘 걸려 기준가 둘레를 **오르내린다**(= 요청한 "다채로운" 등락).

## 안 건드린 것
- 가격 밴드(하한 ×0.4 / 상한 ×10) — 상한은 급등(hype) 체인 연출이 쓰는 값이라 유지.
  `stock-hype-surge-design.md`의 "몇 배 급등"은 그대로 성립한다(틱당 누적 속도만 느려짐).
- 승부처인 `Capitulation`(떨어지는 칼날) 파라미터 — 게이트가 종목 σ 기준이라 자동으로 같이 줄어든다.
- 코인 쪽(`CoinPriceEngine`) 전부.

## 회귀 시 볼 곳
"뉴스를 읽어도 티가 안 난다"면 `NewsEffectMultiplier`를 먼저 올린다(2.2 → 2.6).
"아직도 저점/고점이 극단"이면 `NoiseSigmaFactor`를 더 내린다(0.40 → 0.34).

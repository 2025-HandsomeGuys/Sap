# 주식 급등주(테마주) + 뉴스 신호 강화 설계

작성일: 2026-08-13
선행/상충 문서: [stock-coin-price-design.md](stock-coin-price-design.md) — 이 문서는 그 문서 **§3(뉴스 신호 3배 강화 기각)의 결정을 부분적으로 뒤집는다.** 아래 §5에서 왜 뒤집었는지 명시한다.
목적: (1) 뉴스 신호를 전역으로 강화하고, (2) 가끔 종목이 **몇백 %씩 급등**했다가 **수십 틱에 걸쳐 자연 감쇠**하는 "급등주" 이벤트를 넣고, (3) **오른 뉴스 뒤에 자연스럽게 내리는 뉴스**(거품 붕괴)가 따라오게 한다.

---

## 1. 배경 — 왜 손댔나

`stock-coin-price-design.md`는 초반 주식이 채굴의 7~15%밖에 안 되는 이유를 **"수익률(ρ=3.4%/일)이 아니라 투입 자본 병목(하루소득의 29배 필요)"**으로 정확히 진단했다. 플레이어 체감도 "저금하는 느낌, 돈이 적게 벌린다"였다.

자본 병목을 푸는 가장 재미있는 레버가 **급등주**다. 종잣돈이 적은 초반 플레이어가 급등 한 번 올라타면 자본이 몇 배로 점프해 복리 궤도에 오른다. "잉여 자본 → 투자" 서사와도 맞는다.

동시에 뉴스 신호 자체가 거대한 노이즈(±15~34%/일)에 묻혀 "뉴스 읽는 보람"이 약했다. 전역 배율로 신호를 키웠다.

---

## 2. 구현 — 데이터 주도 (엔진 최소 수정)

별도 급등 서브시스템을 만들지 않고 **기존 뉴스/체인/로컬라이제이션 인프라를 그대로 재사용**했다. 급등은 그냥 "아주 센 뉴스 체인"이고, 뉴스탭·번역·차트에 자동으로 뜬다.

### 2.1 엔진 (`StockPriceEngine.cs`)

- **`NewsEffectMultiplier = 1.6f`** (신규 const): 모든 뉴스의 주가 반영에 곱한다. 일반 뉴스는 이 배율을 곱해도 여전히 1틱 변동 상한(`maxChangePercent`, 20~45%)에 갇힌다.
- **`CalcNewsEffect`가 두 갈래를 out으로 반환**하도록 리팩터링:
  - `normalEffect` — 일반 뉴스(`HypeBypass==0`). 기존처럼 1순위 100% + 나머지 로그감쇄로 합치고, **상한에 갇힌다.**
  - `hypeEffect` — 급등 뉴스(`HypeBypass>0`). **상한을 우회**해서 `totalChange`에 직접 더한다(희귀 점프와 같은 자리). 여러 틱 누적되면 몇 배까지 간다.
- 최종 가격은 여전히 **`basePrice × 0.4 ~ 10` 클램프**로만 제한된다. 급등 상한(×10)은 그대로 **+900%**(기준가의 10배). ⚠ 하한만 0.1→0.4로 올렸다(2026-08-25, 바닥 매수 익스플로잇 차단 — `stock-floor-buy-exploit.md`).

```
totalChange = clamp(noise + normalNews + sentiment + momentum + reversion, -cap, +cap)
totalChange += hypeEffect     // ← 급등: 상한 우회
totalChange += rareJump       // 기존 희귀 단발 점프
price = clamp(price*(1+totalChange), base*0.4, base*10)   // 하한 0.1→0.4 (2026-08-25)
```

### 2.2 데이터 필드

- `NewsTemplate.HypeBypass` (float) 추가. `StockDataLoader`가 CSV `hypeBypass` 컬럼을 읽는다(**컬럼 없으면 0 = 일반 뉴스**, 기존 76행은 무변경으로 안전 — `CsvParser`가 누락 뒤 컬럼을 빈값 처리).

### 2.3 급등/붕괴 체인 (`NewsTemplates.csv` + `NewsChains.csv`)

**4단계 체인 3종** 추가. 각 체인은 태그 1개만 달아 매칭 종목에 **matchScore=1.0(최대 효과)**로 꽂힌다.

| 체인 | 태그 | 노림 층 |
|---|---|---|
| `chain_meme_surge` | consumer | Tier1~2 |
| `chain_resource_squeeze` | materials | Tier1~4 |
| `chain_tech_mania` | software | 전 티어 |

각 체인 4페이즈 (매집→폭등→붕괴→소멸):

| 페이즈 | Phase | sentiment | impact | dur | 대표 outcome | hypeBypass | 역할 |
|---|---|---|---|---|---|---|---|
| 0 매집 | Rumor | Positive | 0.7 | 3 | 70% +0.05 | **0** | 예열(상한 내 소폭 상승) |
| 1 폭등 | Official | Positive | 0.8 | 5 | 70% **+0.17** / 10% −0.05(불발) | **1** | 급등(상한 우회, 몇 배) |
| 2 붕괴 | Official | Negative | 0.7 | 10 | 75% −0.06 | **1** | 내리는 뉴스(길고 완만) |
| 3 소멸 | Fade | Neutral | 0.3 | 16 | 0.0 | 0 | 평균회귀로 수십 틱 마무리 |

- 폭등 페이즈는 `pricingInFactor=0`이라 `WasPricedIn=false` → Official에서 **full impact**가 나온다(선반영 감쇄 안 걸림).
- **"오른 뉴스 → 내리는 뉴스"**: 체인 시스템이 자동으로 폭등(1) 뒤 붕괴(2)를 발행한다. 붕괴는 `dur=10`으로 길고 완만해서 급락이 아니라 **수십 틱 하강**으로 느껴지고, 소멸(3, `dur=16`)의 평균회귀가 마무리한다.
- **불발 리스크**: 폭등 outcome 10%가 −0.05라 급등이 항상 성공하진 않는다(공짜 아님).
- 빈도 제어: 체인 weight=4, `cooldownTicks=30`(전 페이즈). 스폰은 "체인 활성 중 재스폰 금지 + 완료 후 30틱 쿨다운".

### 2.4 로컬라이제이션 (`Stock_Localization.csv`)

체인명 3키 + 뉴스 24키(4페이즈×2×3체인), KR/EN/CN(简体) 추가.

## 3. 시뮬레이션 검증 (실제 CSV + 새 엔진 그대로 포팅)

초반 조건: 시작 3,000G, 하루 채굴 150G(economy §2.5-A 실측), Tier1, 20일, 뉴스단타. N=4,000.

| | 주식순익 평균 | 수익률 | 승률 | 20일 급등발생 | 급등 시 도달배수(중앙) |
|---|---|---|---|---|---|
| 변경 전(신호×1.0) | +3,906G | +65% | 78% | 0.47회 | 3.8x |
| **변경 후(×1.6+급등우회)** | **+6,379G** | **+106%** | 83% | 0.46회 | **4.6x (≈+360%)** |

- **급등은 20일당 ~0.46회** = 20일 플레이의 40%가 급등 1회 목격. "가끔씩" 목표에 부합.
- 급등 시 종목이 **중앙값 4.6배(+360%)**, 상단은 10x 클램프(+900%)까지 → "몇백 %" 실현.
- 초반 주식 수익이 **약 2배**로 뛴다(중앙값 +4,034G). 여전히 초반 절대액은 작지만(자본 병목은 유지) 급등 목격 시 자본 점프가 생긴다.

참고 Tier2(시작 20,000G·하루 6,000G): +113%, 급등 도달 5.6x. 층이 깊을수록 급등 배수가 커지는 건 노이즈·기준가 구조상 자연스럽다.

> 튜닝 다이얼: 급등을 **더 자주** → 체인 weight↑(4→6) 또는 `cooldownTicks`↓(30→20). **더 세게** → 폭등 outcome `priceEffect`↑ 또는 `impactStrength`↑. **더 완만한 하강** → 붕괴 `durationTicks`↑. 신호 전반 → `NewsEffectMultiplier`.

## 4. 왜 안전한가 / 회귀 주의

- 기존 76개 뉴스는 CSV·코드 무변경(hypeBypass 없음=0). `CsvParser`가 누락 뒤 컬럼을 빈값 처리하므로 헤더만 늘려도 안전.
- `CalcNewsEffect` 호출부는 엔진 내부 1곳뿐(확인함). 테스트 러너는 `StockGameManager.ProcessTick`만 부르므로 시그니처 변경 무관.
- 최종 가격 클램프(base×0.4~10, 하한은 2026-08-25에 0.1→0.4)는 그대로라 **가격이 무한 폭주하지 않는다.**
- ⚠ **밸런스 회귀 주의**: `NewsEffectMultiplier`는 **모든** 뉴스를 1.6배 세게 만든다. 부정 체인(팬데믹·칩쇼티지 등)의 하락도 같이 세져 특정 섹터가 더 자주 급락한다. 의도된 방향이지만 "왜 이 종목이 자꾸 빠지지"의 첫 용의자.

## 5. `stock-coin-price-design.md` §3 결정을 뒤집은 이유

그 문서 §3은 "신호를 3배 키우면 일변동 std가 12.6%→35%로 뛰어 스킬이 아니라 운이 지배한다"며 신호 강화를 기각했다. 이번에 부분적으로 뒤집었다:

1. **전역 배율은 3배가 아니라 1.6배**다. std 증가폭이 훨씬 작다(일반 뉴스는 여전히 상한에 갇힘).
2. **극단 변동은 '전 종목 상시'가 아니라 '가끔·특정 테마주에 국한'**된 급등 이벤트로 격리했다. 대부분의 종목·대부분의 날은 예전 변동성 그대로다. "운 지배"가 시장 전체로 번지지 않는다.
3. 급등은 **뉴스탭에 헤드라인으로 뜨고 3페이즈로 예고**되므로 "운"이 아니라 "뉴스 읽고 올라타는 스킬"의 대상이다.

즉 §3의 우려(시장 전체가 도박판이 됨)를 피하면서 급등주 재미만 취했다. **다만 초반 주식이 채굴의 7~15%라는 §4 착지점은 이 변경으로 위로 이동한다**(초반 +106%). "초반 보조"보다 세지는 걸 의도적으로 택한 것이니, 밸런스 재검증 시 이 문서를 근거로 본다.

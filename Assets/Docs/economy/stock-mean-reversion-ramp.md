# 주가 시간-램프 평균회귀 (Time-Ramped Mean Reversion)

작성: 2026-08-14 · 대상: `Assets/Scripts/Stock/Systems/StockPriceEngine.cs`

## 문제

기존 평균회귀는 매 틱 **일정 강도**였다.

```
rev = -log(price / basePrice) * 0.035
```

강도 0.035는 편차를 매 틱 96.5%만 남기므로 반감기가 ~19틱. 즉 뉴스로 벌어진 가격이
**사실상 영구 드리프트**했다. 뉴스가 여러 개 겹치면 상승분이 누적돼 기준가에서 몇 배씩
벌어진 채 돌아오지 않았다(예: 같은 방향 뉴스 3개 겹침 → +716%까지 폭주 후 +356% 잔류).

요구사항:
- 틱이 지날수록 회귀를 **세게** 적용
- 뉴스 종료 후 **3~4틱**이면 기준가 근처로 복귀
- **여러 뉴스가 겹쳐도** 결국 복귀
- 평상시(뉴스 없음) **일일 변동성은 유지**

## 해법 — 이탈 지속 시간에 따라 회귀 강도를 램프

기준가 데드밴드 밖에 **연속으로 머문 틱 수**(`ticksAway`)만큼 회귀 강도를 키운다.

```
ticksAway = PriceHistory 뒤에서부터, |log(p/base)| > log(1+deadband) 인 연속 틱 수
strength  = min(ReversionMax, ReversionBase + ReversionRampPerTick * ticksAway)
rev       = -log(price/base) * strength
```

| 상수 | 값 | 의미 |
|------|-----|------|
| `ReversionBase` | 0.04 | 갓 벌어진 1틱째 강도 |
| `ReversionRampPerTick` | 0.05 | 이탈 지속 1틱당 가산 |
| `ReversionMax` | 0.22 | 강도 상한 |
| `ReversionMaxStepPerTick` | 0.08 | **한 틱 되돌림 이동 상한** (신설) — 아무리 멀어도 회귀는 틱당 ±8%까지만 |
| `ReversionDeadbandPct` | 0.35 | 기준가 ±35% 안 = "복귀 완료"로 간주(리셋) |
| `ReversionDownsideBoost` | 1.0 | (2026-08-25) 하락 대칭 부스트 해제 — 낙폭주가 확실히 안 돌아오게(칼날) |
| `ReversionDelayTicks` | 2 | (2026-08-25) 데드밴드 갓 벗어난 직후 이 틱만큼 램프 미룸(즉발 반등 방지) |

> **⚠ 2026-08-25 (2차) — 낙폭주 무지성 매수 차단:** `ReversionDownsideBoost` 1.4→1.0(하락은
> 상승보다 되돌림이 느려도 됨)·`ReversionDelayTicks`=2 신설(eff_away=away−2)로 "확 빠진 주 다음날
> 바로 반등"을 약화. 이것만으론 부족해 **떨어지는 칼날(Capitulation)** 메커니즘을 추가했다 →
> `economy/stock-falling-knife.md`. 회귀 램프 자체(base/ramp/max)는 1차 값 유지.

램프 스케줄(delay 2 반영, eff_away=away−2): away≤2→0.04, 4→0.14, 6→0.22(cap).
단, 실제 한 틱 되돌림은 `ReversionMaxStepPerTick`(0.08)로 상한 → "최대값으로 팍 당기지 말고 적당히
여러 틱에 걸쳐"(요청). 복귀 측정(vol 0.29, 노이즈 ON): +40% ~22틱 / −40% ~20틱, 틱당 스텝 ≤8%, 침하 0.

> **⚠ 2026-08-25 재튜닝 — 회귀를 느리게(≈15틱 복귀):** 원래 값(base 0.08 / ramp 0.16 / max 0.55,
> 데드밴드 0.15)은 뉴스 3~4틱이면 복귀 → 사고팔 창이 짧고 "돈 벌기 너무 쉬움" 피드백. 강도를 낮춰
> 벌어진 가격이 **천천히** 돌아오게 했다. 몬테카를로(vol 0.29, +40% 뉴스, 4000런 median): **±10%
> 밴드 복귀 = 중첩 15틱 / 단독 14틱**, 뉴스 스파이크는 초반에 유지(t3 +41%, t8 +24%)됐다가 8틱부터
> 완만히 흘러내린다. 최대 강도 0.14 → 편차 반감기 ≈ 4.6틱. 여러 뉴스가 겹쳐도 램프가 결국 이겨
> 복귀하는 성질(영구 드리프트 방지)은 유지. 아래 옛 측정치(3~4틱 복귀)는 원래 값 기준이라 지금과 다르다.
> 함께 변동량도 축소: `NoiseSigmaFactor` 0.86→0.72→(8/25) **0.58**. 틱변동 상한은 이후 `AmbientMaxMove`
> (기본 ±20%)·`MaxTickChange`(총 ±50%)로 하드캡됨 → `stock-volatility-gaussian-and-warmup.md` 상단 노트.
> (중간에 max 0.10/ramp 0.012로 18~22틱까지 늘렸다가, 너무 질질 끌어 15틱으로 되돌린 이력.)

### 하락 대칭 부스트
주가는 곱셈적이라 "−X%"(×(1−X))가 "+X%"(×(1+X))보다 **로그거리가 크다**
(−40%=log0.6=−0.51 vs +40%=log1.4=+0.34). 그래서 대칭 회귀로도 −40%가 +40%보다 복귀가 느렸다
(5틱 vs 3틱). `logRatio<0`일 때만 강도를 `×ReversionDownsideBoost`(상한도 함께)해서
퍼센트 기준 복귀 틱을 맞춘다.

```
strength = min(ReversionMax, ReversionBase + ReversionRampPerTick * ticksAway)
if (logRatio < 0)  strength = min(ReversionMax*Boost, strength*Boost)
```

복귀 틱(결정론, cap 0.30): **±40% → 둘 다 3틱**(정확 일치). ±60%=3/5틱, ±80%=4/6틱 —
큰 충격은 곱셈 동역학상 완전 일치가 불가(−60%는 ×0.4로 복귀에 +150% 필요)해 격차만 절반으로 줄인다.
평상시 기준가 아래 체류 비율도 0.566→0.533으로 대칭에 가까워지고, 일일 변동성은 불변.

### 불변식 — 세이브 새 필드 없음
`ticksAway`는 `CompanyData.PriceHistory`에서 **파생**한다(별도 저장 안 함).
매 틱 시작 시 `CurrentPrice == PriceHistory[^1]`이 성립하므로, 히스토리 뒤에서부터 데드밴드
밖 연속 틱을 세면 "지금까지 벗어나 있던 틱 수"가 된다. 로드 시 히스토리가 복원되면 카운터도
자동 일관. `StockSaveData` 포맷 변경 불필요.

### 데드밴드를 왜 ±15%로 넉넉히?
일일 노이즈가 ±10~18%라 데드밴드가 좁으면 노이즈만으로 램프가 켜져 주가가 기준가에
못박힌다(일변동 死). ±15%로 잡아 **뉴스급(>15%) 이탈만** 강하게 되돌리고, 평상시 노이즈는
자유롭게 흔들리게 둔다.

## 튜닝 근거 (측정)

### 결정론적 감쇠 (노이즈·뉴스 없이, 기준가 1000)
| 충격 | 기존(8틱 후) | 신규(8틱 후) | 신규 ±10% 복귀 |
|------|-------------|-------------|---------------|
| +40% | 1288 (+29%) | 1042 (+4%) | **3틱** |
| +80% | 1554 (+55%) | 1068 (+7%) | **4틱** |
| −40% |  681 (−32%) | — | **3틱** (하락 부스트 적용) |

(하락 부스트 전에는 −40%가 5틱이었다 → 부스트로 +40%와 동일 3틱.)

### 뉴스 겹침 (같은 방향 3개, +0.45/틱, 8틱 지속 후 정지) — median 경로
- 기존: 1000 → 8158(+716%) 정점 → 8틱 뒤에도 **+356% 잔류**
- 신규: 1000 → 3522(+252%) 정점 → 8틱 뒤 **−2% (복귀)**

→ 겹쳐도 복귀 확인. 뉴스 기간 중엔 여전히 크게 오르지만(정점 +252%) 종료 후 되돌아온다.

### 평상시(뉴스 없음) 변동성 유지 — 200틱×300런 평균
| vol | 지표 | 기존 | 신규 |
|-----|------|------|------|
| 0.30 | 평균 일일 변동폭 | 11.3% | **12.1%** (유지) |
| 0.30 | 기준가 평균 이탈 | 37.0% | **14.4%** (억제) |
| 0.30 | 최대 방황 | 124% | **47%** (억제) |

일변동은 그대로, 기준가 이탈만 억제 → "하루 큰 스윙 + 기준가 앵커" 동시 달성.

## 밸런스 영향 (전략 변화)

드리프트가 사라지면서 **핵심 지표가 "최종 잔류"에서 "뉴스 기간 중 잡을 수 있는 정점"으로 이동**한다.

체인별 median (2000런, 희귀점프 제외, 체인 종료 4틱 뒤 잔류):

| 체인 | peak↑ | dip↓ | 종료+4틱 잔류 |
|------|-------|------|--------------|
| construction_boom (호재) | +34% | −22% | −2% |
| crypto_crackdown (악재) | +33% | −33% | −4% |
| food_safety (악재) | +27% | −29% | −3% |
| biotech_frenzy (하이프) | +64% | −35% | −4% |
| defense_scramble (하이프) | +63% | −33% | −3% |

- 모든 체인 잔류 ≈ 0 → 영구 드리프트 제거.
- 호재는 dip이 얕고 악재는 dip이 깊어 방향성 유지.
- 하이프(HypeBypass)는 회귀를 뚫고 정점 +60%대 → 2티어 구조(일반=중간 스윙 / 하이프=큰 스윙) 유지.
- 플레이어 전략: "뉴스로 오를 때 정점에서 팔기 / 악재 패닉 저점 매수 후 복귀 먹기". 버티기(buy&hold)로는 드리프트를 못 먹음.

## ⚠ 동작 변경 (회귀 의심 시 여기부터)
- **(2026-08-18 추가) 이 문서의 복귀 측정은 노이즈 OFF(결정론) 기준이라 변동성 드래그를 못 봤다.**
  라이브(노이즈 ON)에선 곱셈적 갱신의 −½σ² 드리프트가 데드밴드 안의 약한 회귀력을 상쇄해
  고변동주가 기준가로 안 돌아오는 버그가 있었다 → `stock-volatility-drag.md`에서 +½σ² 보정으로 해결.
- 뉴스 후 주가가 **기준가로 돌아온다**(이전엔 벌어진 채 유지). 의도된 변경.
- 하이프 급등도 이전보다 빨리 되돌려진다(정점은 여전히 큼). `HypeBypass`는 1틱 상한만 우회할 뿐
  회귀를 면제받지 않는다.
- `ReversionMax`/`RampPerTick`을 키우면 복귀가 더 빨라지지만 뉴스 스파이크가 눌린다. 반대로
  `ReversionBase`를 키우면 갓 터진 뉴스의 첫 스파이크가 약해진다.
